### Challenges currently resolved

Displaying images on an LCD screen using embedded technologies such as **ESP-IDF, LVGL, and FreeRTOS** taught me how to control display refresh timing and handle errors more permissively regarding tolerable sensor faults, thereby preventing unnecessary reboots of ESP32 devices.
